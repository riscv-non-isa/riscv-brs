The RISC-V Boot and Runtime Services Specification (BRS) defines a standardized
set of software capabilities that portable system software, such as operating
systems and hypervisors, can rely on being present in an implementation. See the
xref:intro.adoc[Introduction] chapter for details, and the navigation for the
full list of chapters.
